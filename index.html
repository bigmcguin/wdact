A starting point for a new website

This page is a placeholder. Swap in the site's real name, colours and words, and it is ready to publish.

Making it your own

  1. Set the site's colours, fonts and spacing in assets/css/theme.css.
  2. Change the site name and menu items in the config at the top of assets/components/nav/nav.js.
  3. Replace the text on this page and on the About page.
  4. Add new pages by copying the head and header from an existing page, then add one line to the menu config.

Publishing

Hostinger copies this repository into public_html whenever main changes, so merging a pull request publishes it straight away.
